# C Programming Examples

This repo contains basic examples written at an introductory level in C programming. The files consist of small homeworks and classic programming problems that will help you understand the algorithm's logic.

## Contents
Files included in the project and their descriptions:

- **Finding_the_Root_of_a_Quadratic_Equation.c**
A program that finds the roots of a quadratic equation.

- **Finding_the_Triangle_Property.c**
A program that determines the type of triangle given its sides.

- **The_dice_are_thrown_100_times.c**
A simulation of throwing a dice 100 times.

- **armstrongnumber.c**
A program that checks whether a number is an Armstrong number.

- **array_calculations.c**
An example that performs various calculations on an array.

- **bubble_sort.c**
A program that sorts using the Bubble Sort algorithm.

- **calculator_(if-else).c**
A simple calculator with an if-else structure.

- **calculator_(switch-case).c**
A simple calculator with a switch-case structure.

- **for addition of twos from 2 to 10.c**
A program that calculates the sum of even numbers from 2 to 10.

- **for factorial.c**
A program that calculates the factorial of a number.

- **for print of twos from 2 to 10.c**
A program that prints even numbers from 2 to 10.

- **making_triangle_stars.c**
A program that draws a triangle shape with stars.

- **max of 3 numbers.c**
A program that finds the largest of three entered numbers.

- **max_value_of_float_series.c**
A program that finds the maximum value in a series of float numbers.

- **perfect_number.c**
A program that checks whether a number is a perfect number.

- **selection_sort.c**
A program that sorts using the Selection Sort algorithm.

- **standard_deviation.c**
A program that calculates the standard deviation of numbers.

- **upper_lower_letter.c**
Returns the number of lowercase and uppercase letters in the text. Then, returns the total number of letters.

- **uppercase-lowercase_vowel_harmony.c**
Checks whether the entered text conforms to the uppercase-lowercase vowel harmony in Turkish.
